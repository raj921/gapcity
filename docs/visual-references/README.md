# GapCity references

Opened in Ego Lite on 9 October 2026. These references guide constraints, not asset copying.

- https://uncut.wtf — readable contemporary sans-serif options. Keep the existing Manrope/DM Sans pairing for continuity; no new font downloads.
- https://number-flow.barvian.me — intentional value transitions and accessible formatting. Keep native Intl formatting: values change only after explicit searches, so animation adds no necessary behavior.
- https://designforb2b.com — product hierarchy and restrained B2B presentation. The map and evidence remain the primary work surfaces.
- https://minimal.gallery — sparse visual hierarchy and whitespace. Keep quiet borders and modest elevation rather than decorative backgrounds.
- https://www.navbar.gallery — static navigation, sidebars and search patterns. Keep search on the left, geographic context in the centre, evidence on the right.
- https://maplibre.org/maplibre-gl-js/docs/ — functional geographic rendering. Version 6.13.0 requires an ES-module `.mjs` import and its CSS; buildings represent geographic data, not review scores.

## UX redesign, 9 October 2026

Current pages were reopened in Ego before implementation. Six direction references:

1. https://styles.refero.design/style/367c0c6e-73a7-441c-a8ff-91d139ac60dc — found in the user's Ego bookmarks. Wise's forest/lime hierarchy informs a single prominent Explore action and quiet secondary controls. Keep GapCity's readable existing fonts, not Wise's enormous display scale. Screenshot: `refero-wise.png`.
2. https://designforb2b.com — separate setup, working surface and inspectable evidence. Keep the search form outside the scrolling result list.
3. https://minimal.gallery — consistent whitespace and restrained surfaces; improve hierarchy without decorative dashboards.
4. https://uncut.wtf — reviewed contemporary sans-serif choices; retain Manrope/DM Sans for continuity and reliable rendering.
5. https://number-flow.barvian.me — format changing counts consistently with tabular numerals. Native Intl remains sufficient; no animation dependency needed for explicit searches.
6. https://dialkit.dev — readable labeled controls and immediate preview feedback. Tune spacing/colors in the running app; no runtime tuning panel needed.

Functional reference: https://maplibre.org/maplibre-gl-js/docs/API/classes/Marker/ — draggable marker and keyboard alternatives. Keep geographic buildings separate from competitor metrics.

Pattern card: a visible setup band, bordered shortlist rows, a generous street map, and a source inspector. Repeat 44 px controls, 10 px corners, forest ink, and lime selection. The purpose is to move a pin, compare observed areas and follow evidence with less scrolling.
